# Oussama El Hajoui

> Snelle websites en web apps met React, Angular, Java en C#. Rechtstreeks samenwerken met software engineer Oussama El Hajoui.

Oussama El Hajoui is een Nederlandse software engineer die snelle websites en webapplicaties ontwerpt en ontwikkelt met React, Angular, Java, C#, Tailwind CSS en Strapi.
